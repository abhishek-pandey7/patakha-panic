# Patakha Panic implementation boundaries

Vite + vanilla ES modules + Matter.js. Shared `src/config.js` defines a 1920 × 960 world, ground Y=780, launcher at {x:190,y:510}, and max speed32. Root owns integration, main.js, docs, browser checks and Git milestones. The balance agent owns physics.js, levels.js and physics tests; the art agent owns art.js; the interface agent owns ui.js and styles.css. Do not commit or push concurrently.

## Physics contract (`src/physics.js`)
Export `GamePhysics`, constructor `(level, onEvent)`. level.pieces is array of `{x,y,w,h,material,group,weak,color,kind}`. `load(level)`, `launch(type, velocity)`, `activate()`, `update(dtMs)`, `getState()`, `destroy()`. State: `{bodies,projectile,progress,score,shotsUsed,remaining,status,combo}`; statuses `ready`, `flight`, `settling`, `won`, `lost`. Bodies keep .plugin data `{piece,health,maxHealth,destroyed,original}`; projectile.plugin.type. `launch` returns bool; projectile launch position above. Event callback `(event)` with `{type:'explosion'|'damage'|'combo'|'launch'|'ability'|'win'|'lose', x,y,radius,message,...}`. Trajectory export `predictTrajectory(velocity,steps=80)` returns points matching physics (velocity in pixels per 60Hz frame). Aim maximum velocity is 32 px/frame. Win at 90% damage/destruction. Engine fixed timestep. Settling guaranteed bounded. `MATERIALS` is the shared material health and damage-multiplier registry used by the UI guide.

## World contract (`src/levels.js`, `src/art.js`)

Updated art direction: pixel art foreground with clear material textures and unique static obstacles; no decorative foreground diyas. The sky and shot corridor remain transparent so the actual uploaded video provides the background. Targets start beyond X=1250; later structures use reinforced and independent supports. Damage and impulse depend on shot power, material/firecracker resistances and severe physical collapse, not small piece displacement.
levels.js exports `LEVELS` (8), `CRACKERS` object (`rocket`, `sutli`, `chakri`, `ladi`) with `{name,color,description,unlockLevel}`. Each level `{id,name,location,hint,shots,unlockedTypes,pieces,par}`. Art exports `SceneRenderer` constructor `(canvas)`, `resize()`, `render(state,dtMs)`; state `{physics,level,time,aim,selected,events,mode,celebrating}` with aim `{pull:{x,y},velocity:{x,y},points}` or null. Render launcher, target pieces, obstacles, projectile, aiming dots and effects. The uploaded video supplies the city. `addEffect(event)` handles particle bursts; `celebrate()` triggers fireworks. Render video separately as DOM element behind canvas (UI ownership). Use provided atlas `public/assets/crackers-reference.png` source rects (1280 square): rocket [40,200,650,345], sutli [790,105,400,530], chakri [75,650,510,525], ladi [610,750,630,410]. Export `drawCracker(ctx,type,x,y,size,angle=0)` for mini canvas UI icons.

## Interface contract (`src/ui.js`, `src/styles.css`, `src/audio.js`, `index.html`)
ui.js export `GameUI`, constructor `(callbacks)` with callbacks `{start,level,select,pause,resume,restart,next,menu,home,music,sound,ability,help}`. Methods `update(state)` where state `{level,physics,selected,save}`, `showScreen(name,data={})` screens `start`, `levels`, `play`, `pause`, `result`, `unlock`, `help`; `toast(message)`; public canvas property or canvas id `game-canvas`. `showScreen('unlock', {type,onClose})`. UI imports LEVELS, CRACKERS and the shared physics material registry; icon mini canvases may import drawCracker. Root creates UI then Renderer then physics. Audio export `GameAudio`, `unlock()`, `setMusic(bool)`, `setSound(bool)`, `play(name)` (launch,rocket,sutli,chakri,ladi,crumble,combo,win), `destroy()`. A muted autoplay looping video at assets/diwali-background.mp4 behind canvas. Main HUD/toolbar active during play; overlay screens functional with callbacks. Save object `{unlocked:1,best:{},seen:[],music:true,sound:true}`, best indexed by level ID with `{score,diyas,progress}`. Play result data `{won,score,progress,diyas,remaining,level,best}`. The original bitmap font is embedded locally in CSS; design responsive landscape with at least 44px touch targets.
